## 四、安全问题

### 1. 密码传输安全
**文件**: `pages/login/login.js` 第59-70行

**问题**: 密码直接传输，建议前端进行加密处理。

**建议**: 在传输前对密码进行 MD5 或 SHA256 加密（后端需要配合修改验证逻辑）。

---

### 2. Token 存储安全
**文件**: `pages/login/login.js` 第77-78行

**问题**: Token 直接存储在 Storage 中，存在安全风险。

**建议**: 
- 设置 Token 过期时间
- 敏感操作时验证 Token 有效性
- 考虑使用微信小程序的安全存储方案

### 2. 列表渲染优化

---

### 3. 防抖节流
**文件**: `pages/jobList/jobList.js` 第44-51行

**问题**: 搜索功能未做防抖处理，频繁触发可能导致性能问题。

**建议**: 添加防抖函数：
```javascript
// 在 utils/util.js 中添加防抖函数
function debounce(fn, delay = 300) {
  let timer = null
  return function(...args) {
    if (timer) clearTimeout(timer)
    timer = setTimeout(() => {
      fn.apply(this, args)
    }, delay)
  }
}
```
