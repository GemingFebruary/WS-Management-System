## 二、数据库设计

### 2.1 数据库选型与设计原则

**数据库类型**: 微信云数据库（MongoDB 兼容的文档型 NoSQL 数据库）

**设计原则**:
1. **三端统一数据源**：小程序、网页端、Flask 后端共享同一云数据库实例，保证数据实时一致
2. **信息快照**：申请提交时冻结学生信息副本，后续个人信息变更不影响历史记录
3. **冗余可控**：适度冗余（如申请中的岗位名称和部门）以提高查询效率
4. **索引优化**：高频查询字段建立索引，复合索引覆盖常见查询组合
5. **安全白名单**：更新操作使用字段白名单，防止越权修改

| `studentId` | String | 是 | 学生学号 |
| `studentName` | String | 是 | 学生姓名 |
| **`studentInfo`** | Object | 否 | **学生信息快照**（提交时冻结） |
| `├─ major` | String | — | 专业（快照） |
| `├─ grade` | String | — | 年级（快照） |
| `├─ phone` | String | — | 电话（快照） |
| `├─ email` | String | — | 邮箱（快照） |
| `├─ college` | String | — | 学院（快照） |
| `├─ gender` | String | — | 性别（快照） |
| `└─ familyType` | String | — | 家庭类型（快照） |
| `jobId` | String | 是 | 岗位 ID |
| `jobName` | String | 是 | 岗位名称（冗余，查询便利） |
| `department` | String | 否 | 部门（冗余） |

| `email` | String | 否 | 邮箱 |
| `availableTime` | String | 否 | 可工作时间 |
| `experience` | String | 否 | 相关经验 |
| `reason` | String | 是 | 申请理由（最大 500 字符） |

| `status` | String | 是 | 状态：`pending`/`approved`/`rejected`/`cancelled` |

**状态流转图**:
```
         ┌──→ approved（通过）
pending ──┼──→ rejected（驳回）─→ 重新申请 → pending
         └──→ cancelled（取消）
```

**业务规则**:
- 同一学生对同一岗位只允许存在一条 `pending` 或 `approved` 记录
- 被驳回（`rejected`）后可重新提交申请
- 已通过或已取消的申请不可再次操作
- 驳回时必须填写 `rejectReason`

### 2.4 数据快照模式

`applications.studentInfo` 采用了**信息快照（Snapshot）**设计模式，这是本系统数据库设计的重要特征。

**设计动机**: 学生在提交申请后可能修改个人资料（专业、年级、手机号等），如果申请记录直接引用用户表，那么后续查看历史申请时看到的是修改后的信息而非申请时的信息，会造成数据溯源困难。

**实现方式**: 申请提交时，将学生当前的 `major`、`grade`、`phone`、`email`、`college`、`gender`、`familyType` 七项信息复制到 `applications.studentInfo` 子文档中，之后学生修改个人资料不会影响已提交申请的快照数据。

**代码位置**:
- 云函数: `cloudfunctions/applications/index.js` — `submitApplication()`
- Flask: `app/routes/applications.py` — `submit_application()`

### 3.2 智能匹配算法

> **代码位置**: `cloudfunctions/jobs/index.js` — `calculateSingleMatchScore()` (第 460-509 行)

这是系统的核心算法，用于计算学生与岗位的匹配度分数。

#### 3.2.1 算法描述

**输入**: 学生信息 `studentInfo`（含 major, grade, gpa, freeTime）和岗位信息 `jobInfo`（含 requiredMajor, requiredGrade, minGpa, workTime）

**输出**: 0-100 的匹配分数（整数）

**算法公式**:

```
MatchScore = Σ(Wi × Mi) / Σ(Wi) × 100

其中:
- 维度1: 专业匹配 (W₁=30%)  M₁ = 1.0 (匹配) | 0.5 (不限/无要求)
- 维度2: 年级匹配 (W₂=20%)  M₂ = 1.0 (匹配) | 0.5 (不限/无要求)
- 维度3: GPA匹配  (W₃=25%)  M₃ = 1.0 (GPA≥要求) | 0.5 (不限/无要求)
- 维度4: 时间匹配 (W₄=25%)  M₄ = checkTimeMatch(freeTime, workTime)
```

**权重设计原理**:
- **专业匹配 (30%)**: 权重最高，因为勤工助学岗位通常要求相关专业背景（如图书馆助理需要图书情报专业）
- **GPA匹配 (25%)**: 反映学生的学习能力，部分岗位有最低成绩要求
- **时间匹配 (25%)**: 确保学生空闲时间与岗位要求不冲突，减少排班问题
- **年级匹配 (20%)**: 某些岗位偏好高年级学生（经验丰富）或低年级学生（可长期在岗）

**特殊情况**:
- 所有维度均无要求时，默认返回 50 分
- 未设置限制条件的维度自动获得 50% 基础分（即该维度得分为权重的一半）
- 最终分数上限限制为 100 分

```javascript
// 伪代码实现
function calculateSingleMatchScore(userInfo, job) {
  let score = 0, totalWeight = 0
  
  // 维度1: 专业匹配 (30%)
  totalWeight += 30
  if (!job.requiredMajor || job.requiredMajor === userInfo.major) {
    score += 30  // 匹配或无要求
  }
  
  // 维度2: 年级匹配 (20%)
  totalWeight += 20
  if (!job.requiredGrade || job.requiredGrade === userInfo.grade) {
    score += 20
  }
  
  // 维度3: GPA匹配 (25%)
  totalWeight += 25
  if (!job.minGpa || job.minGpa <= 0 || userInfo.gpa >= job.minGpa) {
    score += 25
  }
  
  // 维度4: 时间匹配 (25%) - 调用 checkTimeMatch
  totalWeight += 25
  const timeRatio = checkTimeMatch(userInfo.freeTime || '', job.workTime || '')
  score += 25 * timeRatio
  
  // 归一化到 0-100
  return Math.round((score / totalWeight) * 100)
}
```

#### 3.2.2 时间匹配子算法 (`checkTimeMatch`)

> **代码位置**: `cloudfunctions/jobs/index.js` — `checkTimeMatch()` (第 514-535 行)

**输入**: `freeTime` (学生空闲时间描述), `workTime` (岗位工作时间描述)

**输出**: 0.0 ~ 1.0 的时间重叠比率

**算法步骤**:

1. **完全匹配检测**: 若 `freeTime` 包含 `workTime` 或反之（不区分大小写子串匹配）→ 返回 `1.0`
2. **关键词重叠计算**: 统计 10 个时间关键词（`周一`、`周二`、`周三`、`周四`、`周五`、`周六`、`周日`、`上午`、`下午`、`晚上`）在两边文本中同时出现的数量
   - 重叠数 > 0 → 返回 `0.6`
   - 重叠数 = 0 → 返回 `0.2`
3. **空值处理**: 若 `freeTime` 或 `workTime` 为空 → 返回 `0.5`（默认中性值）

```javascript
// 伪代码实现
function checkTimeMatch(freeTime, workTime) {
  if (!freeTime || !workTime) return 0.5
  
  // 完全匹配
  if (freeTime.includes(workTime) || workTime.includes(freeTime)) {
    return 1.0
  }
  
  // 关键词重叠度
  const keywords = ['周一','周二','周三','周四','周五','周六','周日','上午','下午','晚上']
  let overlap = 0
  keywords.forEach(kw => {
    if (freeTime.includes(kw) && workTime.includes(kw)) overlap++
  })
  
  if (overlap > 0) return 0.6
  return 0.2
}
```

**算法评价**: 当前实现为简化版本，存在改进空间：
- 子串匹配误判（如"周一上午"匹配"周一"永远返回 true）
- 关键词权重未区分（"周一上午"与"周一晚上"重叠度同为 2，但前者重叠度更高）
- 建议改进方向：将时间段标准化为 21 个时段（周一~周日 × 上午/下午/晚上），精确计算重叠时段占比

#### 3.3.1 Token 生成与验证

**版本 A — JWT 风格 Token**（jobs、applications、salary、admin 云函数使用）:

```
Token格式: base64({userId, role, iat, exp}).HMAC-SHA256(base64(payload), secret)
```

```javascript
// 生成 Token
function generateToken(userId, role) {
  const payload = { userId, role, iat: Date.now(), exp: Date.now() + 86400000 }
  const header = base64Encode(JSON.stringify(payload))
  const signature = hmacSHA256(header, SECRET)
  return `${header}.${signature}`
}

// 验证 Token
function verifyToken(token) {
  const [header, signature] = token.split('.')
  const expected = hmacSHA256(header, SECRET)
  if (signature !== expected) throw new Error('token无效')
  const payload = JSON.parse(base64Decode(header))
  if (payload.exp < Date.now()) throw new Error('token已过期')
  return payload
}
```

**版本 B — 简单 Base64 Token**（仅 auth 云函数自身使用）:

```
Token格式: base64(userId_timestamp_randomString)
无签名，无过期时间
```

```python
    total_weight = 0
    
    # 维度1: 专业匹配 (30%)
    total_weight += 30
    required_major = job_info.get('requiredMajor', '')
    if not required_major or required_major == user_info.get('major', ''):
        score += 30
    
    # 维度2: 年级匹配 (20%)
    total_weight += 20
    required_grade = job_info.get('requiredGrade', '')
    if not required_grade or required_grade == user_info.get('grade', ''):
        score += 20

    min_gpa = job_info.get('minGpa', 0) or 0
    student_gpa = user_info.get('gpa', 0) or 0
    if min_gpa <= 0 or student_gpa >= min_gpa:
        score += 25
    
    # 维度4: 时间匹配 (25%) — 简化处理，恒为满分
    total_weight += 25
    score += 25
    
    return min(score, 100)
```

```python
from collections import defaultdict

def calculate_salary(month):
    records = SalaryCloud.find_by_month(month)
    
    # 按 studentId 分组
    groups = defaultdict(lambda: {
        'totalHours': 0, 'totalAmount': 0, 
        'paidAmount': 0, 'unpaidAmount': 0, 'recordCount': 0
    })
    for r in records:
        g = groups[r['studentId']]
        g['totalHours'] += r['workHours']
        g['totalAmount'] += r['amount']
        g['recordCount'] += 1
        if r['payStatus'] == 'paid':
            g['paidAmount'] += r['amount']
        else:
            g['unpaidAmount'] += r['amount']
    
    # 补全学生姓名和学院
    result = []
    for student_id, data in groups.items():
        user = UserCloud.find_by_id(student_id)
        status = 'paid' if data['unpaidAmount'] == 0 and data['totalAmount'] > 0 else 'unpaid'
        result.append({
            'studentId': student_id,
            'name': user.get('name', ''),
            'college': user.get('college', ''),
            **data,
            'payStatus': status
        })
    
    # 按总金额降序排列
    result.sort(key=lambda x: x['totalAmount'], reverse=True)
    return result
```

```python
        avg_rate = round(total_amount / total_hours, 2) if total_hours > 0 else 0
        
        user = UserCloud.find_by_id(student_id)
```

```python
def _convert_dates(self, obj):
    """递归转换 {$date: ms} → ISO 字符串, {$oid: hex} → 字符串"""
    if isinstance(obj, dict):
        if '$date' in obj:
            ms = obj['$date']
            return datetime.fromtimestamp(ms / 1000, tz=timezone.utc).isoformat()
        if '$oid' in obj:
            return obj['$oid']
        return {k: self._convert_dates(v) for k, v in obj.items()}
    elif isinstance(obj, list):
        return [self._convert_dates(item) for item in obj]
    return obj
```

> **代码位置**: `utils/util.js` — `calculateMatchScore()` + `checkTimeMatch()`

前端版本与云函数版本的算法**完全一致**，用于岗位列表和推荐页面的即时匹配度展示：

```javascript
function calculateMatchScore(studentInfo, jobInfo) {
  let score = 0, totalWeight = 0
  
  if (jobInfo.requiredMajor) {
    totalWeight += 30
    if (studentInfo.major === jobInfo.requiredMajor) score += 30
  }
  if (jobInfo.requiredGrade) {
    totalWeight += 20
    if (studentInfo.grade === jobInfo.requiredGrade) score += 20
  }
  if (jobInfo.minGpa && jobInfo.minGpa > 0) {
    totalWeight += 25
    if ((studentInfo.gpa || 0) >= jobInfo.minGpa) score += 25
  }
  if (jobInfo.workTime) {
    totalWeight += 25
    score += 25 * checkTimeMatch(studentInfo.freeTime || '', jobInfo.workTime)
  }
  
  return totalWeight > 0 ? Math.round((score / totalWeight) * 100) : 0
}

function checkTimeMatch(freeTime, workTime) {
  if (!freeTime || !workTime) return 0.5
  if (freeTime.includes(workTime) || workTime.includes(freeTime)) return 1.0
  return 0.3  // 有时间但不匹配
}
```

**差异注意**: 前端版 `checkTimeMatch` 返回到 0.3（而非 0.2），且不计算关键词重叠。这是一个与云函数版本的小差异点。

```javascript
function debounce(fn, delay = 300) {
  let timer = null
  return function(...args) {
    if (timer) clearTimeout(timer)
    timer = setTimeout(() => fn.apply(this, args), delay)
  }
}

// 节流：滚动事件使用（300ms 间隔）
function throttle(fn, interval = 300) {
  let lastTime = 0
  return function(...args) {
    const now = Date.now()
    if (now - lastTime >= interval) {
      lastTime = now
      fn.apply(this, args)
    }
  }
}
```

```typescript
const cacheMap = new Map<string, { data: any; timestamp: number }>()
const CACHE_TTL = 30_000  // 30 秒
const MAX_CACHE_SIZE = 50

// 自定义 adapter 拦截 GET 请求
const instance = axios.create({ /* ... */ })
const originalAdapter = instance.defaults.adapter

instance.defaults.adapter = (config) => {
  if (config.method?.toLowerCase() === 'get') {
    const cacheKey = `${config.url}?${JSON.stringify(config.params)}`
    const cached = cacheMap.get(cacheKey)
    
    // 缓存命中且未过期 → 直接返回
    if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
      return Promise.resolve({
        data: cached.data, status: 200, statusText: 'OK',
        headers: {}, config, request: {}
      })
    }
  }
  return originalAdapter(config)
}

// 变更操作后清除缓存

}
```

#### 6.2.2 请求去重

```typescript
// 进行中的请求追踪
const pendingRequests = new Map<string, Promise<any>>()

// 相同 GET 请求共享 Promise
if (config.method?.toLowerCase() === 'get') {
  const key = `${config.url}?${JSON.stringify(config.params)}`
  if (pendingRequests.has(key)) {
    return pendingRequests.get(key)!  // 返回正在进行的 Promise
  }
  const promise = originalAdapter(config)
  pendingRequests.set(key, promise)
```

### 6.3 无限滚动组合式函数

> **代码位置**: `src/composables/useInfiniteScroll.ts`

```typescript
export function useInfiniteScroll<T>(
  fetchFn: (params: { pageNum: number; pageSize: number }) => Promise<{ list: T[]; total: number }>,
  options?: { pageSize?: number; threshold?: number }
) {
  const items = ref<T[]>([])
  const loading = ref(false)
  const hasMore = ref(true)
  let pageNum = 0
  
  async function load() {
    if (loading.value || !hasMore.value) return
    loading.value = true
    pageNum++
    
    const res = await fetchFn({ pageNum, pageSize: options?.pageSize ?? 6 })
    items.value.push(...res.list)
    hasMore.value = items.value.length < res.total
    loading.value = false
    
    // 内容未填满屏幕 → 自动加载下一页
    nextTick(() => {
      if (document.documentElement.scrollHeight <= window.innerHeight && hasMore.value) {
        load()
      }
    })
  }
  
  function refresh() {
    pageNum = 0
    items.value = []
    hasMore.value = true
    load()
  }
  
  // 滚动监听
  function onScroll() {
    const threshold = options?.threshold ?? 50
    if (window.innerHeight + window.scrollY >= document.documentElement.scrollHeight - threshold) {
      load()
    }
  }
  
  onMounted(() => window.addEventListener('scroll', onScroll))
  onUnmounted(() => window.removeEventListener('scroll', onScroll))
  
  return { items, loading, hasMore, load, refresh }
}
```

**设计要点**:
- **类型安全**: 泛型 `<T>` 支持任意数据类型
- **自动预加载**: 首屏内容不够高时自动加载下一页
- **状态封装**: loading/hasMore/refresh 全部内置管理
- **防重复**: loading 状态锁防止并发重复加载

```typescript
  a.download = `发薪清单_${month}.csv`
  a.click()
  URL.revokeObjectURL(url)
}
```

**设计要点**:
- `﻿` UTF-8 BOM 前缀确保 Microsoft Excel 正确识别中文编码
- 每个字段用双引号包裹，防止内容含逗号时错位
- 使用 `Blob` + `URL.createObjectURL` 触发浏览器下载

### 6.6 日期格式化算法

> **代码位置**: `src/utils/date.ts`

```typescript
export function formatDate(date: any): string {
  if (!date) return ''
  
  let d: Date
  
  if (typeof date === 'string') {
    d = new Date(date)
  } else if (date.$date) {
    // MongoDB Extended JSON: {$date: 1781083175517}
    d = new Date(date.$date)
  } else if (date instanceof Date) {
    d = date
  } else if (typeof date === 'number') {
    d = new Date(date)
  } else {
    return ''
  }
  
  const y = d.getFullYear()
  const m = String(d.getMonth() + 1).padStart(2, '0')
  const day = String(d.getDate()).padStart(2, '0')
  return `${y}-${m}-${day}`
}

export function formatDateTime(date: any): string {
  const dateStr = formatDate(date)
  if (!dateStr) return ''
  const d = new Date(date)
  const h = String(d.getHours()).padStart(2, '0')
  const min = String(d.getMinutes()).padStart(2, '0')
  return `${dateStr} ${h}:${min}`
}
```

**多格式兼容**: 同时处理 ISO 字符串、MongoDB `{$date: ms}`、JS Date 对象、数字时间戳四种格式，桥接云数据库和 Python 后端之间的日期表示差异。

### 7.2 差异影响分析

1. **Flask vs 云函数时间匹配**：Flask 后端恒给时间匹配满分，导致 Flask 返回的匹配度偏高。当学生时间不匹配时，Flask 可能显示 75-85 分，而云函数可能显示 55-65 分。
2. **前端 vs 云函数时间匹配**：前端 `checkTimeMatch` 在时间不匹配时返回 0.3，云函数返回 0.2，导致前端计算的匹配度略高于云函数。
3. **建议**: 统一为云函数版本的 `checkTimeMatch` 实现（含关键词重叠计算），部署到 Flask 后端和小程序前端。

### 8.4 已知安全风险

1. **`.env` 文件泄露**: QGPY 的 `.env` 文件包含真实的 `WX_SECRET` 和 `JWT_SECRET_KEY`，虽然 `.gitignore` 已排除，但文件存在于本地磁盘
2. **Token 格式不一致**: auth 云函数生成的 Token 与其他云函数期望的格式不同（见 §3.3.1）
3. **密码重置弱校验**: 管理员重置密码时直接将密码设为学号值，缺乏复杂度要求
