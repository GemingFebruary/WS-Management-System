# 勤工助学岗位匹配管理系统

基于微信云开发的勤工助学岗位匹配管理小程序。

## 快速开始

1. **配置环境ID** - 修改 `app.js` 第8行
2. **上传云函数** - 右键 cloudfunctions 下各文件夹 → "上传并部署：云端安装依赖"
3. **初始化数据库** - 首页点击"初始化数据库"按钮（自动创建索引）
4. **生成测试数据**（可选）- 调用seedData云函数
5. **配置权限** - 参考 [DEVELOPMENT.md](DEVELOPMENT.md)

## 项目特点

- ✅ 智能匹配算法（专业30%、年级20%、成绩25%、时间25%权重）
- ✅ 完整的用户认证系统（登录/注册/权限控制）

- ✅ 申请审核流程

## 技术栈

- **前端**: 微信小程序原生框架（WXML + WXSS + JavaScript）
- **后端**: 微信云开发（CloudBase）
  - 云函数（Node.js）
  - 云数据库（MongoDB）
  - 云存储（可选）
