# 图标说明

由于微信小程序需要使用实际的图片文件作为tabBar图标，请准备以下图标文件（建议尺寸：81x81px）：

## 所需图标文件

1. **home.png** - 首页未选中图标
2. **home-active.png** - 首页选中图标
3. **job.png** - 岗位未选中图标
4. **job-active.png** - 岗位选中图标
5. **profile.png** - 我的未选中图标
6. **profile-active.png** - 我的选中图标

## 图标设计要求

- 颜色：未选中 #999999，选中 #4A90E2
- 格式：PNG（支持透明背景）
- 尺寸：81x81 像素
- 风格：简洁线性图标

## 临时解决方案

在开发阶段，可以暂时注释掉 app.json 中的 tabBar 配置，使用导航按钮进行页面跳转。

或者使用在线图标生成工具生成简单图标。
